# Data Dictionary

Generated by `python -m mandipulse data-dictionary` from the dbt model docs
(`dbt/mandipulse/models/marts/_marts.yml`) and the live column types in Postgres.
All prices are **Rs per quintal** (100 kg) wholesale prices.

Star schema (Postgres schema `marts`):

```
dim_date (date_key) ──┐
dim_market (market_key) ──┼── fact_daily_price (date_key, market_key, commodity_key)
dim_commodity (commodity_key) ──┘
```

Upstream layers: `raw.mandi_prices` → `staging.stg_mandi_prices` (clean, dedupe, aliases)
→ `intermediate.int_price_flags` (quality flags) → `intermediate.int_daily_prices` → marts.


## `marts.dim_date`

Calendar, one row per day from the first to the last date in fact_daily_price.

Rows: 3032

| Column | Type | Description |
|---|---|---|
| `date_key` | integer | Surrogate key, YYYYMMDD as integer. |
| `date` | date | Calendar date. |
| `day_of_week` | integer | ISO day of week, 1 = Monday ... 7 = Sunday. |
| `day_name` | text | Day name, e.g. Monday. |
| `week` | integer | ISO week number (1-53). |
| `month` | integer | Month number (1-12). |
| `month_name` | text | Month name, e.g. January. |
| `quarter` | integer | Calendar quarter (1-4). |
| `year` | integer | Calendar year. |
| `is_weekend` | boolean | True on Saturday and Sunday. |
| `period` | text | 'main' up to 2025-10-31 (analysis window); 'post_format_change' from 2025-11-01. |

## `marts.dim_market`

One row per canonical market (state x district x canonical market name).

Rows: 595

| Column | Type | Description |
|---|---|---|
| `market_key` | text | Surrogate key, md5 of 'state\|district\|market'. |
| `market` | text | Canonical market name (raw names mapped via reference.market_aliases; ' APMC' suffix removed). |
| `district` | text | District, after reference.district_corrections. Spellings as in the source (older names). |
| `state` | text | State. |
| `latitude` | double precision | WGS-84 latitude from the geocode cache (or manual override). |
| `longitude` | double precision | WGS-84 longitude from the geocode cache (or manual override). |
| `geo_precision` | text | 'market' (town/locality-level hit), 'district_centroid' (fallback), 'manual' (override) or 'not_found'. |
| `town_key` | text | md5 of the rounded coordinate pair. Markets with identical coordinates (same-town yards, or markets sharing a district centroid) share a town_key. |
| `first_report_date` | date | First date with a valid daily price for any commodity. |
| `last_report_date` | date | Last date with a valid daily price for any commodity. |
| `n_report_days` | bigint | Distinct dates with a valid daily price for any commodity. |
| `n_markets_in_town` | bigint | Number of markets sharing this market's town_key. |

## `marts.fact_daily_price`

One row per date x market x commodity, from valid rows only. Gaps are not filled.

Rows: 1770723

| Column | Type | Description |
|---|---|---|
| `date_key` | integer | FK to dim_date. |
| `market_key` | text | FK to dim_market. |
| `commodity_key` | integer | FK to dim_commodity. |
| `modal_price` | numeric | Median of the valid modal prices across varieties/grades that day, Rs per quintal. |
| `min_price` | numeric | Lowest valid min price across varieties/grades that day, Rs per quintal. |
| `max_price` | numeric | Highest valid max price across varieties/grades that day, Rs per quintal. |
| `n_varieties` | bigint | Distinct varieties behind the day's price. |
| `n_rows` | bigint | Valid staging rows aggregated into this row. |
| `source` | text | Source tag(s) of the underlying rows, comma-separated (today always 'kaggle_archive'). |
| `period` | text | 'main' or 'post_format_change' (see dim_date.period). |
